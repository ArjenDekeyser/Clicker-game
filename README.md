# Moon Orchard: Cosmic Clicker

An original, multi-world idle clicker. Click the central object to collect each world’s currency, buy upgrades, automate production, and explore new environments.

## Play

Open `index.html` in a modern browser. Keep `world-packs.js` beside it; that file provides the later worlds. Progress saves automatically in the browser on this device.
