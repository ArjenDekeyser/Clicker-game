# Moon Orchard: Cosmic Clicker

An original, multi-world idle clicker. Click the central object to collect each world’s currency, buy upgrades, automate production, and explore new environments.

## Play

Open `index.html` in a modern browser. Keep `world-packs.js` beside it; that file provides the later worlds. Progress saves automatically in the browser on this device.

## Progression

- Click the moon, bubble, or gear to collect the current world’s currency.
- Buy 30 upgrades per world across click power, autoclicking, producers, and global boosts.
- Unlock five regions in each world; later regions give stronger production bonuses.
- Complete eight milestones and eight expeditions to open the World Gate.
- Spend Star Shards from expeditions on permanent constellation paths.
- Entering the next world resets the current world’s currencies, upgrades, regions, rebirths, and path ranks. Each new world has its own environment, clicker, currency, gardens, upgrades, milestones, and expeditions.
- Cosmic Rebirths are available within each world and grant that world’s permanent production tokens.

## Worlds

1. **Moon Orchard** — collect Stardust in a lunar garden.
2. **Abyssal Archive** — gather Pearls in an underwater reef.
3. **Clockwork Wilds** — harvest Gears in an enchanted mechanical forest.

## Other features

- Local saves and an offline harvest capped at eight hours
- Developer controls from the moon button (code: `jens is de beste`)
- Responsive layout, sound toggle, and reset confirmation
